# Игры для 3 и 4 класса — инструкция для Claude

Проект: учебные игры для двух девочек (3 и 4 класс, гимназия, Беларусь) — математика, русский, белорусский, английский.
Это Angular-оболочка (хаб «Игры») + все уже сделанные игры в виде самодостаточных HTML (`public/legacy/`).
Задача на будущее — постепенно переносить игры на Angular, не ломая то, чем ребёнок пользуется каждый день.

Отвечай владелице проекта (Волха) **по-русски**, неформально и честно: если идея плохая — скажи.

## Где что лежит

| Путь | Что это |
|---|---|
| `src/app/core/games.ts` | Каталог игр (класс, предмет, цвет, legacy-путь / Angular-маршрут). Хаб строится из него. |
| `src/app/core/progress.ts` | Звёзды/уровни (`lvlAt`, `levelOf`), безопасный `store` для localStorage, `ProgressService`. |
| `src/app/hub/` | Хаб «Игры» с вкладками «3 класс / 4 класс». |
| `public/legacy/<игра>/index.html` | **Рабочие** игры. Каждая — один файл: HTML+CSS+JS+шрифты внутри, работает офлайн. Сейчас это источник правды. |
| `legacy-src/` | Исходники, из которых собирались некоторые legacy-игры (см. `legacy-src/README.md`). |
| `docs/games.md` | Суть каждой игры: режимы, данные, педагогические правила. **Читать перед правками игры.** |

| `docs/open-items.md` | Что не доделано и что Волха должна проверить. |
| `tools/publish.mjs` | Сборка и выкладка на GitHub Pages. |
| `tools/smoke.mjs` | Дымовой тест: все игры открываются, кнопка «назад» ведёт в хаб. |

## Публикация (после КАЖДОГО изменения)

1. Проект лежит в репозитории **v-litovka/uroki** в папке `ng/`. Собранное приложение — в `app/` этого же репозитория.
2. `npm run publish` → собирает с `--base-href /uroki/app/` и копирует сборку в `../app`.
3. `git add -A && git commit && git push` из корня репозитория.
4. Адрес: **https://v-litovka.github.io/uroki/app/** (старый сайт https://v-litovka.github.io/uroki/ продолжает работать параллельно).

Правило Волхи: любое изменение сразу пушится на GitHub — ребёнок открывает игры на iPad по ссылке.
Прогресс (localStorage) общий для старого и нового адреса — это один домен `v-litovka.github.io`, ключи те же.

## Жёсткие правила контента (нарушать нельзя)

- **Никогда не упоминать «мама»** ни в одном тексте, задаче, подсказке. Если в учебнике «мама купила…» — переформулировать («Купили 4 кг свёклы…», «Тёте 36 лет…»).
- **3 класс**: в примерах — кошки **Вира** (толстая, пушистая, белая с чёрными пятнами как корова, обожает есть и валяться на полу) и **Венди** (худая, серо-коричневая); также смешное, мультики, Minecraft, Roblox. Тексты для 3-классницы могут быть в женском роде («Начертила», «Запомнила»).
- **4 класс**: **кошек не использовать**. Можно Roblox и собаку **Луну** (средняя мексиканская голая собака, обожает еду и всегда выпрашивает, любит играть и бегать) и то, что нравится 4-классникам. Тексты — **нейтральные по роду** (не «сделала», а «Готово», «Проверить»).
- Схемы задач — как в учебнике/у учителя, ничего самовыдуманного. Задачи на К1 · К = ОК (количество в одном, количество, общее количество) — таблицей.
- Дети не читают длинные правила: объяснение — несколько слов, лучше выбор кнопкой.
- После правильного ответа — шаг **«Почему?»**: 2 коротких варианта причины (верная и неверная). Кнопки с единственным ответом можно блокировать на ~5 с, чтобы ребёнок прочитал.
- Неразрывные пробелы: `8 · 8 = 64`, `64 кг` не должны разрываться переносом (в legacy это делает скрипт `nbsp`, в Angular — пайп/директива, см. migration.md). В тестах сравнивай текст через `\s`, а не обычный пробел.

## Домашка — особые правила (самая чувствительная игра)

- **Никогда не показывать ответ.** Ни в вопросе, ни в подсказке. Подсказки наводят («направляй»), а не говорят, что делать.
  Пример: для «начерти треугольник» — выбрать тип угла по картинкам (тупой/прямой/острый), ввести длины сторон из текста, потом «начерти в тетради с линейкой».
- Данные ребёнок **сначала вводит сам**, и только потом они появляются на доске/в таблице/на схеме.
- Промежуточные вычисления «карандашом» (серые строки) — **только для сложного счёта** (умножение + сложение, двузначные числа). Простое (см + мм) — сразу пример и ответ.
- Ответ к задаче — **полным предложением**: «36 кг клубники собрал Игорь».
- В задачах «во сколько раз / на сколько» — сначала шаг «что сравниваем» с вводом, потом отображение, потом счёт.
- Родительский режим — за паролем **2924**.
- Задания добавляются по фото страниц тетради/учебника, которые присылает Волха.

## Награды (одинаково во всех играх)

`lvlAt = n => 5*n*(n+3)` → уровни на 20, 50, 90, 140, 200… звёздах. Звёзды не сгорают, «пропусков» нет.

## Как работать с legacy-игрой

- **Источник правды теперь здесь** — `ng/public/legacy/`. Старые папки в корне репозитория (`/ulica`, `/slova`, …) — замороженная копия
  старого сайта; правки туда больше не вносим (когда новый адрес проверен — корневые страницы можно заменить редиректами на `app/`).

- Правь прямо `public/legacy/<игра>/index.html` (это минифицированно-читаемый один файл; ищи по `const STREETS`, `const ITEMS`, `const TOPICS`, `const BLOCKS`).
- Ссылка «← Игры» внутри игр ведёт на `../../#/3` (3 класс) или `../../../#/4` (4 класс) — не ломай.
- Проверяй на ширине **390 px** (телефон) и на iPad. Playwright: `tools/smoke.mjs` + свои сценарии.
- Новая игра: лучше сразу на Angular (см. migration.md), плитку добавить в `games.ts`.
