# Перенос legacy-игр на Angular

Сначала прочитай `docs/architecture.md`. Образец переноса — **Работа над ошибками** (`content/grade-3/ru/rabota/`): старая версия осталась в `public/legacy/rabota/` (ссылка «Старая версия игры» внизу пака).

## Порядок для одной игры

1. Прочитать её раздел в `docs/games.md` и исходник (`public/legacy/<игра>/index.html` или `legacy-src/<игра>/`).
2. **Данные** → `content/grade-N/<предмет>/<игра>/data.ts` (как есть, только типизировать). Это главная ценность — ничего не потерять.
3. Элементы → `items.ts`, режимы → `modes.ts` (каждый режим: элемент → шаги), `pack.ts`.
4. Если не хватает типа шага — добавить (рецепт в architecture.md), а не писать отдельный компонент под игру.
5. `legacyStorageKey` = старый ключ игры (`KEY='…'` в её HTML) — звёзды перенесутся. Если формат старого прогресса другой — дописать конвертер в ProgressService.
6. Плитку в `entries.ts` переключить на `kind: 'pack'`, legacy-путь — в `LEGACY_FALLBACK`.
7. `npm test && npx ng build && npm run e2e`, глазами на 390 px, выложить, дать ребёнку попробовать. Legacy удалять только после этого.
