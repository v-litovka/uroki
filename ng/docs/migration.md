# Перенос на Angular

Игры **не обязательно** переписывать сразу: хаб уже на Angular, legacy-игры работают из `public/legacy/`.
Переносить по одной, когда игру всё равно надо серьёзно менять.

## Порядок для одной игры

1. Прочитать её раздел в `docs/games.md` и исходник (`public/legacy/<игра>/index.html` или `legacy-src/<игра>/`).
2. Вынести **данные** в `src/app/games/<игра>/data.ts` (типизированные массивы — это 80 % ценности, их нельзя потерять).
3. Сделать компонент `src/app/games/<игра>/<игра>.ts` (standalone, signals), lazy-маршрут в `app.routes.ts`:
   `{ path: 'play/<игра>', loadComponent: () => import('./games/<игра>/<игра>').then(m => m.X) }`.
4. В `games.ts` поменять `status: 'angular'`, `route: '/play/<игра>'`.
5. **Сохранить ключ localStorage** или написать миграцию из старого ключа (иначе ребёнок потеряет звёзды!).
6. Сравнить поведение со старой версией (Playwright, 390 px), выложить, попросить ребёнка попробовать. Только потом удалять legacy.

## Общие компоненты (сделать один раз, первыми)

| Компонент | Что делает в legacy |
|---|---|
| `TopBar` | домой, звёзды ⭐ + «ур. N», кнопка звука |
| `ProgressService` (готов) | звёзды, уровни, `done`-флаги, безопасный localStorage |
| `Sfx` | WebAudio: ok / bad / tap / fin (функция `tone`) |
| `Cats` | SVG-кошки `vira(mood,size)` / `wendy(mood,size)`, настроения happy/sad/sly (см. `legacy-src/english/cats.js`) — только 3 класс |
| `Options` | сетка кнопок-ответов; неверная краснеет и блокируется, верная зеленеет; опционально блокировка на N секунд |
| `AnswerInput` | ввод + «Проверить», нормализация (ё=е, регистр, пробелы), тряска при ошибке |
| `WhyStep` | «Почему?» — 1 верная + 1–2 неверных причины, перемешаны |
| `Feedback` | плашка с кошкой и короткой фразой |
| `Round` | N заданий, очередь повторов ошибок, итог «с первого раза X из N», +звёзды, тост нового уровня |
| `nbsp` | директива/пайп: неразрывные пробелы вокруг `· : + − = × < >` и между числом и единицей |
| `Speech` | speechSynthesis с выбором голоса ru/en, режим скрывается, если голоса нет |

Схемы задач (`drawScheme`, `ktable`, `drawMotion`) — отдельные SVG-компоненты, их удобно покрыть snapshot-тестами.

## Кандидаты по порядку

1. **Работа над ошибками** — маленькая, свежая, данные уже структурированы (`legacy-src/rabota/app.js`).
2. **Стишок умножения** — данные в `legacy-src/stih/blocks.py`.
3. **Домашка** — самая большая и ценная; движок шагов хорошо ложится на компоненты (`pick/num/nums/multi/order/note`).
4. Города (Слов/Слоў/Задач) — общий движок «улиц», можно сделать один движок на 6 игр.
